# Веб-каталог кружков и секций с регистрацией участников

Дипломный проект. Стек: React (Vite) + Node.js/Express + PostgreSQL.

## Что нужно установить

- Node.js 18+ (https://nodejs.org)
- PostgreSQL 14+ (https://www.postgresql.org/download/)

## Запуск (4 шага)

### 1. База данных
Создайте пустую базу (в pgAdmin или командой):

```
psql -U postgres -c "CREATE DATABASE kruzhki;"
```

### 2. Сервер
```
cd server
npm install
copy .env.example .env      (Linux/Mac: cp .env.example .env)
```
Откройте `.env` и поставьте свой пароль от PostgreSQL в `DATABASE_URL` и любую длинную строку в `JWT_SECRET`. Затем:
```
npm run db:init     # создаёт таблицы
npm run db:seed     # добавляет демо-данные
npm start           # запускает API на http://localhost:4000
```

### 3. Клиент (в новом окне терминала)
```
cd client
npm install
npm run dev         # сайт на http://localhost:5173
```

### 4. Вход
| Роль | Email | Пароль |
| --- | --- | --- |
| Администратор | admin@kruzhki.local | admin123 |
| Организатор | organizer@kruzhki.local | org12345 |
| Участник | user@kruzhki.local | user1234 |

## Уведомления организатору о новых записях

Когда кто-то записывается в кружок, **организатору этого кружка** приходит письмо: ребёнок, год рождения, родитель, телефон, комментарий и ссылка на раздел «Заявки». Адрес берётся из email организатора в его аккаунте. Родителю (если у него настоящая почта) приходят письма «заявка принята» и «подтверждена/отклонена».

Чтобы письма приходили на твою почту, зарегистрируйся как организатор с адресом `tepmuhatop338@gmail.com` и создай кружок, либо используй демо-организатора: для демо-аккаунтов (`@kruzhki.local`) письма идут на запасной адрес `NOTIFY_EMAIL`.

Чтобы сайт мог отправлять письма, один раз настрой отправителя (Gmail):

1. В аккаунте Google включите **двухэтапную аутентификацию**: https://myaccount.google.com/security
2. Откройте https://myaccount.google.com/apppasswords, создайте пароль приложения (имя любое, например `kruzhki`) и скопируйте 16 символов.
3. В `server/.env` добавьте (пример в `.env.example`):
```
NOTIFY_EMAIL=tepmuhatop338@gmail.com   # запасной адрес для демо-организаторов
MAIL_USER=tepmuhatop338@gmail.com
MAIL_PASS=ваш16символьныйпароль
```
4. Перезапустите сервер (`Ctrl+C`, затем `npm start`). В терминале при заявке появится строка `[почта] ... отправлено`.

Это пароль приложения, а не пароль от почты. Никому не показывайте его и не публикуйте `.env`. Без настройки сайт работает как раньше, а в терминале пишет «почта не настроена». Для проверки без отправки добавьте в `.env` строку `MAIL_MODE=console`.

## WhatsApp

В файле `client/.env` (создайте копированием `client/.env.example`) укажите номер цифрами с кодом страны, без плюса и пробелов:
```
VITE_WHATSAPP_PHONE=77001234567
```
Перезапустите сайт (`Ctrl+C`, затем `npm run dev`). Зелёная кнопка внизу справа, кнопка в карточке кружка и ссылка в подвале будут открывать ваш чат (`wa.me/номер`) с готовым текстом.

## Автоматическая проверка API (необязательно)

При запущенном сервере и чистой базе (`npm run db:init`, `npm run db:seed`):
```
cd server
npm test
```
Ожидаемый итог: «пройдено 20 из 20». После теста снова выполните `db:init` и `db:seed`, чтобы вернуть демо-данные.
