# ТЗ: Веб-каталог кружков и секций с регистрацией участников

> Документ для ИИ-агента и разработчика. Всё, что не входит в раздел «MVP», не делаем, пока MVP не заработает.

## 1. Цель проекта

Создать веб-сайт, где:

- **родители и участники** находят кружки и секции в каталоге (поиск, фильтры) и записываются онлайн;
- **организаторы** (руководители кружков) публикуют свои кружки и управляют заявками;
- **администратор** следит за порядком на сайте.

Проблема, которую решаем: информация о кружках разбросана по соцсетям и объявлениям, запись идёт по телефону.

## 2. Стек

| Часть | Технология |
| --- | --- |
| Фронтенд | React (Vite), React Router |
| Бэкенд | Node.js + Express |
| База данных | PostgreSQL |
| Авторизация | JWT (токен) + bcrypt (хеширование паролей) |
| Валидация | express-validator (или zod) |
| Стили | обычный CSS или Tailwind CSS |

## 3. Роли пользователей

| Роль | Что может |
| --- | --- |
| **Гость** | Смотреть каталог и карточки кружков, искать и фильтровать, зарегистрироваться и войти |
| **Участник** (родитель или взрослый ученик) | Всё, что гость, плюс: записаться в кружок, видеть и отменять свои заявки, редактировать профиль |
| **Организатор** | Создавать, редактировать и скрывать **свои** кружки, задавать расписание, видеть заявки на свои кружки и подтверждать или отклонять их |
| **Администратор** | Управлять категориями, видеть и блокировать пользователей, скрывать любой кружок |

## 4. Список функций

### MVP — обязательно (8 функций)

1. Регистрация и вход (участник, организатор), выход.
2. Каталог кружков: карточки, поиск по названию, фильтры (категория, возраст, бесплатные).
3. Страница кружка: описание, расписание, адрес, контакты, число свободных мест.
4. Запись в кружок: форма (ребёнок, год рождения, телефон) с контролем мест и защитой от повторной заявки.
5. Кабинет участника: мои заявки со статусами, отмена заявки.
6. Кабинет организатора: создать, изменить, скрыть кружок, задать расписание.
7. Заявки организатора: список, кнопки «Подтвердить» и «Отклонить».
8. Админ-панель: категории, блокировка пользователей, скрытие кружков.

### Если останется время

- Отзывы и оценки кружков
- Избранное
- Загрузка фото кружка
- Email-уведомления о смене статуса заявки
- Карта с расположением кружков
- Пагинация и сортировка (по цене, по новизне)
- Адаптивная вёрстка для телефонов (желательно сделать сразу, но без идеала)

### Не делаем

Онлайн-оплату, мобильное приложение, интеграции с внешними сервисами (Госуслуги, соцсети), чат.

### registrations
| Поле | Тип | Описание |
| --- | --- | --- |
| id | SERIAL PK | |
| user_id | INT FK → users.id | кто подал заявку |
| club_id | INT FK → clubs.id | |
| participant_name | VARCHAR(100) | кого записывают |
| participant_birth_year | INT | |
| phone | VARCHAR(20) | |
| comment | TEXT | |
| status | VARCHAR(20) | `pending` / `confirmed` / `rejected` / `cancelled` |
| created_at | TIMESTAMP | |

Ограничение: уникальный индекс по (club_id, user_id, participant_name) для заявок со статусом `pending` / `confirmed` — запрет повторной активной заявки (после отмены можно записаться снова).

### Связи

- Один организатор → много кружков (`users 1:N clubs`)
- Одна категория → много кружков (`categories 1:N clubs`)
- Один кружок → много занятий в расписании (`clubs 1:N schedules`)
- Один пользователь → много заявок, один кружок → много заявок (`users 1:N registrations`, `clubs 1:N registrations`)

### Позже (если останется время)

`reviews` (id, user_id, club_id, rating 1–5, text, created_at) и `favorites` (user_id, club_id).

## 7. Основные API-маршруты

Формат ответов: JSON. Защищённые маршруты требуют заголовок `Authorization: Bearer <token>`.

### Авторизация
| Метод | Маршрут | Доступ | Действие |
| --- | --- | --- | --- |
| POST | `/api/auth/register` | все | регистрация (роль: participant или organizer) |
| POST | `/api/auth/login` | все | вход, возвращает токен |
| GET | `/api/auth/me` | авторизованные | данные текущего пользователя |

### Каталог
| Метод | Маршрут | Доступ | Действие |
| --- | --- | --- | --- |
| GET | `/api/categories` | все | список категорий |
| GET | `/api/clubs?search=&category=&age=&free=` | все | каталог с фильтрами (только активные) |
| GET | `/api/clubs/:id` | все | карточка кружка с расписанием и числом свободных мест |

### Организатор
| Метод | Маршрут | Доступ | Действие |
| --- | --- | --- | --- |
| GET | `/api/organizer/clubs` | организатор | мои кружки |
| POST | `/api/organizer/clubs` | организатор | создать кружок |
| PUT | `/api/organizer/clubs/:id` | организатор (владелец) | изменить кружок и расписание |
| DELETE | `/api/organizer/clubs/:id` | организатор (владелец) | скрыть/удалить кружок |
| GET | `/api/organizer/registrations` | организатор | заявки на мои кружки |
| PATCH | `/api/organizer/registrations/:id` | организатор (владелец кружка) | изменить статус: confirmed / rejected |

### Участник
| Метод | Маршрут | Доступ | Действие |
| --- | --- | --- | --- |
| POST | `/api/registrations` | участник | подать заявку на кружок |
| GET | `/api/registrations/my` | участник | мои заявки |
| PATCH | `/api/registrations/:id/cancel` | участник (владелец) | отменить заявку |
| PUT | `/api/profile` | авторизованные | изменить профиль |

### Админ
| Метод | Маршрут | Доступ | Действие |
| --- | --- | --- | --- |
| GET | `/api/admin/users` | админ | список пользователей |
| PATCH | `/api/admin/users/:id/block` | админ | заблокировать / разблокировать |
| POST / PUT / DELETE | `/api/admin/categories` | админ | управление категориями |
| PATCH | `/api/admin/clubs/:id/hide` | админ | скрыть любой кружок |

## 8. Бизнес-правила и требования

1. Пароли хранятся только в виде хеша (bcrypt), никогда открытым текстом.
2. Роль `admin` создаётся вручную (скрипт `seed`), через форму регистрации её получить нельзя.
3. Организатор может изменять только **свои** кружки; участник видит только **свои** заявки. Проверка выполняется на сервере.
4. Заявка со статусом `pending` или `confirmed` занимает место. Свободных мест = `capacity − количество таких заявок`.
5. При вводе данных валидация на фронтенде **и** на бэкенде (email, обязательные поля, возраст, цена ≥ 0).
6. Заблокированный пользователь не может войти.
7. Сайт должен нормально выглядеть на компьютере; адаптив под телефон — по возможности.
8. Данные для демонстрации: seed-скрипт создаёт админа, 5–6 категорий и 8–10 кружков.

## 10. Порядок разработки (для ИИ-агента)

1. База данных: `schema.sql` + `seed.sql`.
2. Сервер: подключение к БД, регистрация и вход (JWT), middleware ролей.
3. API каталога (список, фильтры, карточка).
4. Фронтенд: каталог и страница кружка.
5. Запись в кружок и «Мои заявки».
6. Кабинет организатора: кружки и заявки.
7. Админ-панель.
8. Проверка правил из раздела 8, исправление ошибок, README с инструкцией запуска.
