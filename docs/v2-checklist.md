## Проверка после распаковки

В локальной среде разработчика выполнить только на тестовой/локальной базе:

```bash
cd server
npm run db:reset
npm run db:init
npm run db:seed
npm test
npm run test:unit
```

`db:reset` удаляет данные выбранной базы. Не запускать на базе с нужными данными.

Перед запуском `db:reset` убедиться, что база тестовая и важные данные сохранены.
