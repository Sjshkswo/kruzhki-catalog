# Разбор конкурентов

Тема: «Разработка веб-каталога кружков и секций с регистрацией участников»

| Сервис | Что делает пользователь | Что делает администратор | Что взять в свой проект |
| --- | --- | --- | --- |
| **Навигатор дополнительного образования** (региональные порталы, например 66.pfdo.ru) | Ищет кружок в каталоге, смотрит расписание, подаёт электронную заявку, ведёт личный кабинет | Организации размещают программы и группы, принимают заявки; органы образования видят данные онлайн | Каталог с карточками, электронная заявка, личный кабинет |
| **Госуслуги — «Запись в кружки и секции»** | Входит через подтверждённую учётную запись, сравнивает кружки, подбирает на карте ближайшие к дому, записывается на программу | Организация открывает набор в группы; если группа заполнена, запись закрыта | Статусы заявки, закрытие записи при заполнении группы |
| **Okushy** (Казахстан) | Сравнивает варианты, читает отзывы, записывается на пробные занятия онлайн | Организации размещают свои предложения на одной платформе | Отзывы, пробное занятие (в разделе «Если останется время») |
| **«Кружки и секции» / «Я родитель» (Санкт-Петербург)** | Ищет городские секции по фильтрам, в том числе для детей с особыми потребностями, строит маршрут до места | Город публикует и обновляет каталог (большая часть кружков бесплатная) | Фильтры по возрасту, цене, категории |
| **МЭШ — раздел «Кружки» (Москва)** | Получает список рекомендованных занятий по возрасту ребёнка, ищет по названию | Школы и департамент ведут список кружков | Подбор по возрасту, поиск по названию |

## Выводы для проекта

1. Во всех сервисах есть **каталог с поиском и фильтрами** — это ядро сайта.
2. Везде есть **заявка/запись** со статусом и личный кабинет.
3. У организатора обязательно есть **своя панель** для кружков и заявок.
4. Отзывы, карта и пробные занятия — удобно, но для MVP это лишнее.

## Собственные наблюдения

_Раздел заполняется автором после ручной проверки не менее двух из перечисленных сервисов._
